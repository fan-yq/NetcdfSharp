# NetcdfSharp 功能范围文档

> 依据当前代码库编译/测试实际状态编写。配套文档：[`使用指南.md`](使用指南.md)（面向使用者）。

## 项目定位

netcdf-java（maint-5.x）的 Java→C# 1:1 移植。**明确目标：本地文件读取** netCDF-3 / netCDF-4（HDF5）/ HDF4 / HDF5 / GRIB1 / GRIB2 / BUFR。

**明确不做**：远程访问（DAP/OPeNDAP、gCDM、流式）、netCDF-4 写入、特性数据集处理。**netCDF-3 写入已实现**（见 §2 与测试覆盖）。

## 一、已实现功能

### 1. 格式读取（按验证程度分级）

| 格式 | 读取实现 | 验证状态 |
|---|---|---|
| netCDF-3（classic） | `nc2/internal/iosp/netcdf3/N3iospNew` + `N3headerNew` | ✅ **有 mock-data 测试** |
| netCDF-4（HDF5） | `nc2/internal/iosp/hdf5/H5iospNew` + `H5headerNew` + `H5objects` | ✅ **有 mock-data 测试** |
| HDF5（纯 HDF5 文件） | 同上（H5iospNew 同时识别纯 HDF5） | ✅ **有 mock-data 测试** |
| HDF4 | `nc2/internal/iosp/hdf4/H4iosp` + `H4header` | ⚠️ 已编译，样例 `test_hdf4.hdf` 存在但**未接入测试** |
| GRIB1 | `Grib1Iosp` + `Grib1DataReader`（Grib 项目） | ✅ **有记录/读取测试**（`Grib1RecordsTests`、`GribRecordReadTests`） |
| GRIB2 | `Grib2Iosp` + `Grib2DataReader`（Grib 项目） | ✅ **有记录/读取测试**（`Grib2RecordsTests`、`GribRecordReadTests`） |
| BUFR | `BufrIosp2` + `BufrIospBuilder`（Bufr 项目） | ✅ **已编译（0 错误），有 mock-data 测试**（`test_bufr.bufr`，`BufrModuleReadTests`）；工厂已排除（见二） |

netCDF-3/4/HDF5 已验证的能力：基础读取、shape/DataType 正确、全局与变量/分组属性、zlib/gzip 压缩解压、分块存储、shuffle、`_FillValue`、多类型元素读取（float/int/short/byte）。

### 2. 核心数据模型（`ucar.ma2` / `ucar.nc2`）

- `ucar.ma2`：`NcArray`（原 `Array`，已更名）、`Index`、`Range`、`Section`、`DataType`、`StructureData`/`ArrayStructure`/`ArraySequence`/`StructureMembers`、`IndexIterator` 等数组与结构层
- `ucar.nc2`：`NetcdfFile`、`Group`、`Variable`、`Attribute`、`Dimension`、`EnumTypedef`、`Structure`/`Sequence`、入口 `NetcdfFiles.open(...)`
- 过滤器（HDF5/netCDF-4 压缩解压）：`deflate/zlib`、`shuffle`、`scaleoffset`、`unsigned` 等（`nc2/filter/`）

### 3. 单位与时间

- Core 内置最小 `ucar.units` 垫片（**`Shim*` 前缀**）：单位字符串解析（含 `"X since date"` 时间单位）、基础单位换算
- `ucar.nc2.units`：`SimpleUnit` / `TimeUnit` / `CalendarDateUnit`（netCDF 时间坐标 → 日期，mock 测试中时间坐标可正常解析）
- Udunits **完整移植项目**（`NetcdfSharp.Udunits`）：编译通过（含手写 `StandardUnitFormat` 解析器、`SI`、`StandardUnitDB` 等），目前未被 Core 读路径调用

### 4. 投影与地理坐标

- `ucar.unidata.geoloc`：`LatLonPoint`、`Projection`/`ProjectionImpl`、常用投影（Mercator、Stereographic、LambertConformal、AlbersEqualArea、TransverseMercator、RotatedPole 等）、`Earth`/`EarthEllipsoid`

### 5. 元数据读取

- 全局属性、变量属性、分组属性均可读取；`units`/`standard_name`/`long_name`/`scale_factor`/`add_offset`/`coordinates`/`_FillValue`/`flag_values` 等（mock 测试已验证）

### 6. netCDF-3 写入

- `NetcdfFormatWriter`（`nc2/write/`）：`createNewNetcdf3`/`createNewNetcdf3c64`/`openExisting` + Builder（addDimension/addVariable/addStructure/addAttribute/addUnlimitedDimension）
- `N3iospWriter`/`N3headerWriter`（`nc2/internal/iosp/netcdf3/`）：header 序列化、record/non-record 布局、fill 值、unlimited 追加、openExisting 续写、`updateAttribute`、preallocate
- 往返测试 `Netcdf3WriteTests`：固定维度 double 2D、unlimited 追加、openExisting 续写、CHAR 变量、标量、全局属性、byte（7 用例）
- 范围：仅 **netCDF-3 / 64-bit offset**；netCDF-4 写入不支持（构造抛 `NotSupportedException`）

| 文件 | 原因 |

| `unidata/io/RemoteRandomAccessFile.cs`、`MMapRandomAccessFile.cs` | 远程/内存映射读取（远程范围外） |

| `NetcdfSharp.Bufr/.../BufrFeatureDatasetFactory.cs` | 依赖 `ucar.nc2.ft` 特性子系统（范围外） |

### 2. 以垫片/占位实现（可编译，功能未实现）

| 垫片位置 | 说明 |
|---|---|
| `nc2/dataset/DatasetStubs.cs` | **dataset 增强层未移植**：`NetcdfDataset`/`VariableDS`/`StructureDS`/`CoordinateSystem` 为 stub → `scale_factor`/`add_offset` **不自动应用**（`NetcdfFile.readData` 返回存储原始值）、坐标系统不构建、枚举/缺失值增强不生效 |
| `ucar.units/Units.cs`（Core 垫片） | 最小单位实现，仅覆盖 `ucar.nc2.units` 时间/单位需求 |
| `Grib/grib/stubs/*` | 范围外模块占位：`thredds.featurecollection`、`ucar.nc2.ft2`、`coverage`、`partition`、`GribIndex`/`GribCdmIndex`、`GribCollectionWriter`（索引写入）、`Jpeg2000`/jj2000、`HTTPRandomAccessFile`、`MSGnavigation`、`ImmutableListMultimap` 等 |
| `Grib2JpegDecoder` | **不做实际 JPEG2000 解码**（jj2000 为垫片，`decode` 抛 `NotSupportedException`）；故含 JPEG2000 压缩的 GRIB2 数据无法读取 |

### 3. 缺失 / 未实现

- **Bufr 特性数据集层**：`ucar.nc2.ft` 特性子系统未移植；`BufrFeatureDatasetFactory.cs` 已排除编译。`BufrCdmIndexProto` 手写为普通 C# 枚举（`FldType`/`FldAction`，无 Google.Protobuf）；`.ncx` 索引持久化范围外。
- **netCDF-3 写入**：已实现 `NetcdfFormatWriter`（`nc2/write/`）+ `N3iospWriter`/`N3headerWriter`，**有往返测试**（固定维度/unlimited 追加/CHAR/标量/全局属性/byte，7 用例）
- **netCDF-4 写入**：无。Java 原版经 JNA 调原生 netCDF-C（`ucar.nc2.jni.netcdf.Nc4Iosp`，不在 cdm/core），无纯 Java 实现可移植；本仓库 `NetcdfFormatWriter` 对 netCDF-4 格式抛 `NotSupportedException`
- **DAP/远程**：完全无（`RemoteRandomAccessFile` 已排除，`HTTPRandomAccessFile` 为垫片）

### 4. 未做运行时验证的路径

- HDF4 / GRIB1 / GRIB2 读路径：编译通过，样例文件存在于 `mock-datasets/` 但**未接入测试**，**未运行时验证**
- HDF5 复合类型 / 变长字符串的深层读取：部分路径未经测试覆盖
- HDF5-EOS（`HdfEos`）：存在，未验证

## 三、测试覆盖

- 测试项目：`NetcdfSharp.Tests`（xUnit，引用 Core / Udunits / Grib / **Bufr**）
- 用例：**340 个全部通过**
  - 读取：netCDF-3、netCDF-4、HDF5、自定义数据类型、xarray 生成的 netCDF4（`MockDataReadTests`）
  - ma2/nc2 模型与 IOSP：数组/结构/分组/维度/属性/过滤/时间/单位（`ucar.ma2`、`ucar.nc2.*`）
  - GRIB：GRIB1/GRIB2 记录解析与读取、坐标、WMO/本地码表（`ucar.nc2.grib.*`）
  - **写入往返**：`Netcdf3WriteTests`（固定维度 double 2D、unlimited 追加、openExisting 续写、CHAR、标量、全局属性、byte）
  - **BUFR 读取**：`BufrModuleReadTests`（mock `test_bufr.bufr`，eccodes BUFR4 模板消息）
- 数据生成：仓库根目录 `python generate_mock_data.py`（产物在 gitignored 的 `mock-datasets/`）
- 运行：`dotnet test .\NetcdfSharp.Tests`
