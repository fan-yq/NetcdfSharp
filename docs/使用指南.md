# 使用指南

> 面向**使用者**：如何在 .NET 10 项目里用 NetcdfSharp 读取 netCDF-3 / netCDF-4 / HDF5 / HDF4 / GRIB / BUFR 本地文件。
> 现状：**netCDF-3 / netCDF-4 / HDF5 / GRIB1 / GRIB2 / BUFR 已可读（有测试验证）**；HDF4 已编译但**未接入测试**（见 [`功能范围.md`](功能范围.md)）。

---

## 1. 引用方式

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
  </PropertyGroup>
  <ItemGroup>
    <ProjectReference Include="..\NetcdfSharp.Core\NetcdfSharp.Core.csproj" />
    <!-- 读 GRIB 需要 -->
    <ProjectReference Include="..\NetcdfSharp.Grib\NetcdfSharp.Grib.csproj" />
    <!-- 读 BUFR 需要 -->
    <ProjectReference Include="..\NetcdfSharp.Bufr\NetcdfSharp.Bufr.csproj" />
  </ItemGroup>
</Project>
```

> 所有公共类型都在 `ucar.*` 命名空间下。核心入口在 `ucar.nc2`，数据载体在 `ucar.ma2`。

常用 using：

```csharp
using ucar.nc2;        // NetcdfFile, NetcdfFiles, Variable, Group, NcAttribute
using ucar.ma2;        // NcArray, DataType, Section, NcRange
using ucar.nc2.constants; // CDM 常量（SCALE_FACTOR 等）
```

## 2. 最小示例：打开并读一个变量

```csharp
using (NetcdfFile nc = NetcdfFiles.open(@"C:\data\wind\netcdf3.nc"))
{
    // 1) 按名找变量（支持分组路径，如 "satellite_data/radiance"）
    Variable temp = nc.findVariable("temperature");
    if (temp == null)
    {
        Console.WriteLine("变量不存在");
        return;
    }

    // 2) 元数据
    Console.WriteLine($"name={temp.ShortName} type={temp.DataType} shape=[{string.Join(",", temp.Shape)}]");
    Console.WriteLine($"units={temp.findAttributeString("units", "(无)")}");
    Console.WriteLine($"standard_name={temp.findAttributeString("standard_name", "(无)")}");

    // 3) 读取全量数据
    NcArray data = temp.read();                 // 等价 read(Section.fill(null, temp.Shape))
    Console.WriteLine($"size={data.Size}");

    // 4) 按线性下标取元素（Java 语义的 getXxx）
    double first = data.getDouble(0);           // 自动按需类型转换
    float  firstF = data.getFloat(0);
    int    firstI = data.getInt(0);
}
```

要点：

- `NetcdfFile` 实现 `IDisposable`，用 `using` 释放。
- `Variable.read()` 读整个变量；`read(section)` 读子集；`readScalarFloat()` 等读标量。
- `NcArray.getXxx(int)` 按**线性下标**访问，自动做类型转换（float 变量可用 `getDouble` 读）。

## 3. 读取子集（Section / NcRange）

```csharp
// 取 temperature[0..4, 1..3, *]：第 0 维 0..4、第 1 维 1..3、第 2 维全取
Section sec = new Section(
    new NcRange(0, 4),
    new NcRange(1, 3),
    new NcRange(0, temp.Shape[2] - 1));
NcArray sub = temp.read(sec);

// 或用字符串规格（与 netcdf-java 的 section spec 一致）
NcArray sub2 = temp.read("0:4,1:3,:");

// 切片：固定某一维
Variable slice = temp.slice(0, 2);
```

## 4. 属性读取

```csharp
// 全局属性
Console.WriteLine(nc.RootGroup.findAttributeString("Conventions", "(无)"));
Console.WriteLine(nc.RootGroup.findAttributeString("title", "(无)"));

// 变量属性
NcAttribute scale = temp.findAttribute(CDM.SCALE_FACTOR);
NcAttribute fill  = temp.findAttribute("_FillValue");
if (scale != null)
{
    Console.WriteLine($"scale_factor={scale.NumericValue}");   // object，需 Convert 转换
}
```

> ⚠️ **`scale_factor` / `add_offset` 不会被自动应用**：dataset 增强层未移植（`NetcdfDataset` 是 stub），`readData`/`read` 返回**存储的原始打包值**。需要物理值时自行 `raw * scale + offset`。`_FillValue` 同理只作为属性存在，不自动替换缺失值。

## 6. 各格式支持情况

| 格式 | 打开 | 说明 |
|---|---|---|
| netCDF-3（classic） | ✅ | 测试验证 |
| netCDF-4（HDF5） | ✅ | 分组、zlib 压缩、分块、shuffle 测试验证 |
| HDF5（纯 HDF5） | ✅ | 测试验证 |
| HDF4 | ⚠️ | 编译通过，未运行时验证 |
| GRIB1 / GRIB2 | ✅ | 记录/读取测试验证（`Grib1RecordsTests`/`Grib2RecordsTests`/`GribRecordReadTests`）；标准入口 `NetcdfFiles.open` 打开并读取全部变量（`GribStandardOpenTests`）；JPEG2000(模板 5.40) 压缩数据**不可读**（垫片抛 `NotSupportedException`） |
| BUFR | ✅ | mock-data 读取测试验证（`BufrModuleReadTests`），含标准入口 `NetcdfFiles.open`；特性数据集层范围外 |

## 7. 已知限制（读之前先看）

1. **netCDF-3 写入已支持**（见 §9）；**netCDF-4 写入**不支持。**远程访问**完全不支持。
2. **GRIB2 JPEG2000 压缩**：`Grib2JpegDecoder` 为垫片，遇到模板 5.40 数据抛 `NotSupportedException`。
3. **索引缓存**：不做 `.ncx`/`.gbx9`，每次打开全量扫描，大文件打开较慢。
4. **`scale_factor`/`add_offset`/缺失值增强**：不自动应用。
5. **netCDF 假想历法**（`360_day`/`noleap`）：`ucar.nc2.time.Calendar` 已移植，时间单位字符串解析可用；但完整 date 对象 API 未全部暴露。

## 8. 错误处理

```csharp
try
{
    using (NetcdfFile nc = NetcdfFiles.open(path))
    {
        // ...
    }
}
catch (System.IO.IOException e)
{
    Console.WriteLine($"打开失败: {e.Message}");
}
```

格式嗅探由 IOSP 注册表自动完成（按文件签名/扩展名），无需手动指定格式。

## 9. 写入 netCDF-3（`NetcdfFormatWriter`）

```csharp
using ucar.nc2.write;   // NetcdfFormatWriter

string filename = @"C:\data\out\netcdf3.nc";

// 1) 构建元数据
NetcdfFormatWriter.Builder writerb = NetcdfFormatWriter.createNewNetcdf3(filename);
Dimension lat = writerb.addDimension("lat", 64);
Dimension lon = writerb.addDimension("lon", 128);
writerb.addVariable("temperature", DataType.DOUBLE, "lat lon")
       .addAttribute(new NcAttribute("units", "K"));
writerb.addAttribute(new NcAttribute("title", "my dataset"));

// 2) build 后只能写数据，不能再加元数据
using (NetcdfFormatWriter writer = writerb.build())
{
    // 写全量：origin 默认为 0
    NcArray data = NcArray.factory(DataType.DOUBLE, new[] { 64, 128 });
    // ... 填充 data ...
    writer.write("temperature", data);

    // 或指定 origin 写子块
    // writer.write("temperature", new[] { 0, 0 }, data);
}
```

要点：

- `createNewNetcdf3(location)` 建新文件；`createNewNetcdf3c64` 建 64-bit offset 版；`openExisting(location)` 打开已存在文件续写数据（不能加元数据）。
- `addUnlimitedDimension("time")` + `addVariable(..., "time")` 可写 record 变量；`write` 沿 unlimited 维追加，重开文件再写即续写。
- `setFill(false)` 关闭 fill 值预写（更快，但未写到的位置不保证有 fill）；`setPreallocateSize(n)` 预分配文件大小。
- 写入 CHAR 变量用 `ArrayChar`（见 `ArrayChar.D1`）；标量变量用 `ArrayXxx.D0`。
- **netCDF-4 写入不支持**（`createNewNetcdf4` 已移除，netCDF-4 格式在 build 时抛 `NotSupportedException`）。
- 已实现并测试的往返能力：固定维度 / unlimited 追加 / openExisting 续写 / CHAR / 标量 / 全局属性 / byte（`Netcdf3WriteTests`，7 用例）。
